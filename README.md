# 🔧 AWS Cloud Deployment Labs – Hands-On Learning Path


Welcome to my curated collection of **AWS cloud deployment labs**, designed as a progressive, hands-on learning path.  
This repository focuses on **real-world AWS deployment patterns**, moving from serverless architectures to containers, managed orchestration, and Kubernetes on AWS.

Each project is structured to reflect **how modern cloud workloads are actually built and deployed**, with clear documentation and reproducible steps.

Each project includes:
- A dedicated project folder
- Clear execution guides
- Architecture-focused documentation
- Practical CLI and console-based workflows
- Hands-on validation steps

This repository highlights my **cloud engineering mindset**, deployment expertise, and ability to document infrastructure clearly.

---

## 📁 Repository Structure

### ⚡ Serverless
**01-serverless-rest-api**  
Build and deploy a serverless REST API using AWS Lambda and Amazon API Gateway, including external API integration and request handling.

---

### 📦 Containers & Image Management
**02-containerized-nginx-ecr**  
Containerize an NGINX web application using Docker and push the image securely to Amazon Elastic Container Registry (ECR).

---

### 🚀 Managed Containers (Serverless Compute)
**03-ecs-fargate-web-app**  
Deploy a containerized web application on Amazon ECS using AWS Fargate, eliminating the need to manage EC2 instances.

---

### ☸️ Kubernetes & Orchestration
**04-eks-nginx-deployment**  
Provision an Amazon EKS cluster, deploy an NGINX application using Kubernetes manifests, expose it via a LoadBalancer service, and manage cluster resources.

---

## 🚀 Learning Path Breakdown

### 1️⃣ Serverless Foundations
Lambda functions, API Gateway integration, request handling, and external API communication.

### 2️⃣ Containerization Fundamentals
Docker-based application packaging and secure image storage using Amazon ECR.

### 3️⃣ Managed Container Orchestration
Running containerized workloads on Amazon ECS with Fargate for serverless container execution.

### 4️⃣ Kubernetes on AWS
Cluster provisioning, IAM integration, VPC networking, Kubernetes deployments, and AWS-managed load balancers using Amazon EKS.
