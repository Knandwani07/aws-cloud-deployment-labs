# 🚀 Containerized NGINX Web Application Deployment Using Amazon ECR  
## 📌 Project Level: Beginner → Intermediate  

A hands-on AWS project where you containerize a simple **NGINX-based web application** using Docker and securely store the container image in **Amazon Elastic Container Registry (ECR)**.  
This project demonstrates how container images are built, authenticated, pushed, and validated using AWS-managed container services.

---

## 📝 Project Overview  
This project walks through creating an Amazon ECR repository, configuring an IAM user for secure access, building a Docker image for an NGINX web application, pushing the image to ECR, and running the container locally to validate the deployment.

It highlights the complete container image lifecycle and establishes strong fundamentals in Docker workflows, AWS IAM security, and Docker–AWS integration.

---

## 🎯 Objective  
To containerize an NGINX web application using Docker, store the image securely in Amazon ECR, and validate the container by running it locally.

---

## 🧰 AWS Services Used  
- **Amazon ECR** — Managed container image repository  
- **AWS IAM** — Secure access control for ECR operations  
- **AWS CLI** — Command-line interface for AWS authentication  
- **Docker Engine & Docker Desktop** — Container build and execution  
- **NGINX** — Lightweight web server used as the base image  

---

## 🧠 What This Project Teaches  
- Understanding container image workflows  
- Creating and managing Amazon ECR repositories  
- Configuring IAM users with least-privilege access  
- Authenticating Docker with AWS  
- Building, tagging, and pushing Docker images  
- Running and validating containers locally  
- Cleaning up cloud and local resources responsibly  

---

## 🚀 Project Steps (Simplified)  
1. Create a private Amazon ECR repository.  
2. Create an IAM user with ECR permissions.  
3. Configure AWS CLI on the local machine.  
4. Verify Docker installation and setup.  
5. Authenticate Docker with Amazon ECR.  
6. Create a Dockerfile and application files.  
7. Build, tag, and push the Docker image to ECR.  
8. Run the container locally and validate output.  

---

## 🌟 Key Features  
- Secure private container registry

- Real-world container image workflow  

---

## 🧹 Cleanup  
To prevent unwanted charges and clutter:  
- Delete the Docker image locally  
- Delete the Amazon ECR repository  
- Delete the IAM user created for the project
