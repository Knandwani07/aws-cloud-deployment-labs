# ⚡ Building a Serverless REST API Using AWS Lambda and Amazon API Gateway  
## 📌 Project Level: Beginner → Intermediate  

A hands-on AWS project where you build a **fully functional REST API** without provisioning or managing any servers.  
This project demonstrates how modern applications handle **scalable request processing** using serverless compute and managed API services.

---

## 📝 Project Overview  
This project walks through creating an **AWS Lambda function**, integrating it with an external REST API, configuring **Amazon API Gateway**, enabling **CORS**, deploying the API, and validating responses using browser-based testing and API clients.

It highlights how backend logic can be executed **on demand**, while AWS automatically handles **scaling, availability, and infrastructure management**.

---

## 🎯 Objective  
To build and deploy a **serverless REST API** using AWS Lambda and Amazon API Gateway, integrate it with an external API, and validate **end-to-end request and response flow** without managing servers.

---

## 🧰 AWS Services Used  
- **AWS Lambda** — Serverless compute for backend logic  
- **Amazon API Gateway** — REST API creation and request routing  
- **IAM Roles** — Secure permission management for Lambda execution  
- **CloudWatch Logs** — Monitoring and debugging Lambda executions  
- **External REST API** — Third-party data source for integration testing  

---

## 🧠 What This Project Teaches  
- Understanding serverless architecture fundamentals  
- Creating and testing AWS Lambda functions  
- Integrating Lambda with external REST APIs  
- Configuring API Gateway resources, methods, and stages  
- Enabling and managing CORS  
- Testing APIs using Lambda test events, API Gateway console, and Postman  
- Deploying and exposing a public REST API endpoint  

---

## 🚀 Project Steps (Simplified)  
1. Create and test an AWS Lambda function using Python.  
2. Integrate the Lambda function with an external REST API.  
3. Create a REST API using Amazon API Gateway.  
4. Configure GET methods and enable CORS.  
5. Deploy the API to a stage (dev).  
6. Test the API using a browser and Postman.  
7. Add API Gateway as a trigger for Lambda.  
8. Validate end-to-end request → response flow.  

---

## 🌟 Key Features  
- Fully serverless architecture  
- No server provisioning or maintenance  
- Automatic scaling based on request volume  
- Pay-per-use execution model  
- Secure IAM-based permissions  
- Clean separation between API layer and compute logic  

---

## 🧹 Cleanup  
To prevent unwanted charges:  
- Delete the AWS Lambda function  
- Delete the REST API from Amazon API Gateway  
- Remove associated CloudWatch log groups if required

You gain hands-on experience building a **scalable, low-maintenance, cloud-native REST API** using AWS serverless services.  
This project strengthens your understanding of **event-driven architecture**, API management, and modern backend design patterns.
